# IA1 Data Test Prep

A one-page revision site for the Year 11 Psychology IA1 data test (brain function and memory).

It covers:

- descriptive statistics: mean, median, mode, range, IQR, standard deviation, standard error and confidence intervals
- Pearson r, p-values, and paired vs unpaired t-tests
- cognitive verbs and how to write "draw a conclusion" answers
- worked answers to the practice datasets
- a quiz, a brain and memory reasoning bank, and a cheat sheet

Open `index.html` in a browser. It is a single file with no build step.
